# Lift & Fuel

Gym, calorie, body measurement and photo tracker. Data is stored on your device.

## Get the Android APK
1. Push this repo to GitHub (branch `main`).
2. Open the **Actions** tab. The "Build Android APK" workflow runs on every push (about 5 minutes).
3. On your phone, open the repo's **Releases** page, download `lift-and-fuel.apk` from "Latest APK" and tap it to install (allow installs from this source).

## Use it as a web app (optional)
Settings > Pages > Source: **GitHub Actions**. The "Deploy web app" workflow publishes `www/` at
`https://<your-username>.github.io/<repo-name>/`. Open it in Chrome and choose Install app.
